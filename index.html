Restrictions — 사용 금지

✕색상 하드코딩 — 변수 변경 시 누락 발생var(--main-color)
✕space 변수를 요소 간 gap에 사용 — 역할 혼용gap 변수 사용
✕gap 변수를 섹션 패딩에 사용 — 역할 혼용space 변수 사용
✕.con-inner 에 좌우 패딩 추가 — 구조 파괴.section 에서 처리
✕.section 좌우 safe 패딩 제거 — 필수 규칙 위반항상 유지
✕--one-space-safe 반응형 변경 — 16px 고정변경 금지
✕타입 클래스에 line-height 직접 선언.lh-lg 추가
✕.txt-wrap 없이 타입 클래스 사용 — 스코프 이탈.txt-wrap 하위에서만
✕미디어 쿼리 내 신규 변수 선언:root 에 선언 후 재정의
✕!important 남용 — 여백 초기화·.lh-lg 에만 허용필요 시 제한
